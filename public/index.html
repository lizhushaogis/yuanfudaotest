MODEL CONNECTION

连接你的模型服务

要让模型根据每次的新需求生成内容，需要先运行本项目的 Node 代理。API Key 粘贴在项目根目录的 .env 文件里，不要粘贴到网页或 GitHub。网页这里只填写代理地址。

本机按 README 启动后填 http://127.0.0.1:4173；如果你把代理部署到云端，就填云端 HTTPS 根地址。GitHub Pages 本身只提供静态页面。 这是你为代理服务设置的访问口令，不是模型供应商的 API Key。
API Key 的准确粘贴位置LAB_API_KEY=你的模型 API Key文件位置：项目根目录 .env。同时填写 LAB_API_BASE 和 LAB_MODEL，再运行 node --env-file=.env server.mjs。
ABOUT THE PROJECT

从想法到实验的六步

这个工作台把一条教学需求变成一个可检查、可运行、可下载的交互项目。你不需要先懂提示词工程，也不需要先连接 API。

01 · 输入需求

写一句“给谁学、学什么、希望学生做什么”。

02 · 生成项目

系统推断交互类型，生成条件、反馈和结论。

03 · 审核方案

检查探究问题、观察条件和教学结论是否合理。

04 · 查看规则

查看开始、选择、反馈、完成和重置的状态机。

05 · 运行预览

在网页里点击开始，逐项观察反馈并完成实验。

06 · 导出交付

下载项目 JSON、Markdown 文档、Prompt 和独立 HTML。

本地生成器与模型模式

本地生成器会根据新的自然语言需求推断交互类型，并生成项目 JSON、文档和网页；模型模式通过代理让模型补充需求理解。两种模式都经过结构校验，实验为概念示意，正式课程仍需学科审核和用户测试。
