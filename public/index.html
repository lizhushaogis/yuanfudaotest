ABOUT THE PROJECT

从想法到实验的六步

这个工作台把一条教学需求变成一个可检查、可运行、可下载的交互项目。本地生成器无需 API，任何打开链接的人都可以独立输入、修改、预览和下载；要让模型参与新项目生成，才需要连接模型代理。你不需要先懂提示词工程。

01 · 输入需求

写一句“给谁学、学什么、希望学生做什么”。

02 · 生成场景

模型从主题重新设计具体空间、拖拽元素、放置区域、错误提示和反馈关系。

03 · 生成方案

把场景落实为探究问题、观察条件、结论和可执行状态机。

04 · 校验落实

检查主题相关性、条件数量、状态转移和不能发生的错误。

05 · 运行预览

在网页里点击开始，拖动主题元素并完成观察。

06 · 导出交付

下载项目 JSON、Markdown 文档、Prompt 和独立 HTML。

HOW THE WORK IS DONE

这项工作不是“让 AI 随便写一页网页”

先把教学目标拆成可观察的条件，再把条件落实为按钮、反馈、完成条件和重置规则；最后用同一个项目 JSON 同步方案、文档、资源和预览。模型负责理解和提出草案，系统负责结构校验、主题相关性检查和可执行预览，人工负责学科准确性审核。

角色教育交互设计助手任务把需求变成项目草案上下文学习者、主题、目标、条件约束只用已实现交互，不编造数据格式固定 JSON 字段验收主题相关、可操作、可重置
提示词工程，用大白话说：不是写一句“帮我生成”，而是把角色、背景、任务、边界、输出格式和检查标准一次说清楚，让模型稳定地产出能被程序接住的结果。
本地生成器与模型模式

本地生成器提供无需密钥的结构预览；模型模式通过代理根据每次新需求重新生成主题场景、用户动作、画面元素和反馈，再收敛为项目 JSON、文档和网页。内部交互骨架只负责状态安全，用户不需要从固定模板中选择。两种模式都经过结构校验，实验为概念示意，正式课程仍需学科审核和用户测试。
