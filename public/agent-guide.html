启动真正操作网页的测试Agent

1．先启动你电脑上的服务

在项目目录 D:\gpt\ai-lab-workbench 打开终端，运行：

npm run agent

保持服务运行，再打开 本机Agent页面 →。静态网站不能替你的电脑启动浏览器服务；别人在另一台电脑打开这个地址，访问的是他自己的电脑。

2．先点两个自测按钮

故意有缺陷版应失败，修复版应通过。两次都有实际操作和截图。它们是执行器脚本自测，不花API额度，不假称由LLM驱动。

3．再填测试模型，上传HTML

填兼容API地址、模型名和Key，上传你生成的海洋HTML，确认调用后启动。模型会观察控件、选择操作；浏览器执行，程序判定重置结果。最多20轮模型调用，约2分钟，保留页面查看日志。

这版能测什么？

改变深度滑杆→点击记录→确认新增记录→点击重置→确认记录清空、深度恢复。检查点必须有前后证据。找不到控件、缺少可见列表、超时或步骤用尽，都不能判通过。

暂不支持通用15题、Canvas内部状态、子iframe控件、自动拖拽或修复。结果只代表这一条运行检查，不代表科学正确、全部功能或学习效果。仅测试可信或已审查的生成HTML。

结果在哪里？

本机页面显示操作日志、断言和截图；也可下载JSON。文件保存在项目的agent-results目录中，不上传GitHub，不保存模型密钥。
